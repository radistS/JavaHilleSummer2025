# 📝 Завдання для закріплення Stream API

## 🔹 `filter`
1. Залишити зі списку чисел тільки парні.
2. Залишити тільки непарні числа.
3. Залишити числа більше 100.
4. Вибрати рядки довжиною більше 5 символів.
5. Вибрати рядки, які починаються з літери `"A"`.
6. Зі списку людей (`Person`) залишити тільки повнолітніх (вік > 18).
7. Залишити зі списку людей тих, у кого email закінчується на `".com"`.
8. Вибрати тільки прості числа зі списку.
9. Залишити тільки ті рядки, що містять цифри.
10. Вибрати зі списку лише ті рядки, що є паліндромами.

## 🔹 `map`
11. Перетворити список рядків у список їх довжин.
12. Перетворити список чисел у список їх квадратів.
13. Перетворити список чисел у список їхніх коренів.
14. Перетворити список `Person` у список імен.
15. Перетворити список рядків у верхній регістр.
16. Перетворити список дат у список років.
17. Перетворити список слів у список перших літер.
18. Перетворити числа у список рядкових представлень (`123 → "123"`).
19. Перетворити список рядків у їх довжини та видалити дублікати.
20. Перетворити список користувачів у список email-адрес.

## 🔹 `limit`
21. Вивести перші 5 чисел зі списку.
22. Вивести перші 3 рядки зі списку.
23. Вибрати перших 10 користувачів, відсортованих за віком.
24. Вибрати перші 7 чисел після сортування за зростанням.
25. Вивести перші 2 елементи, більші за 100.

## 🔹 `skip`
26. Пропустити перші 5 чисел.
27. Пропустити перші 3 рядки.
28. Пропустити перших 10 користувачів.
29. Пропустити перші 2 елементи, що більші за 50.
30. Пропустити перші 5 чисел після сортування.

## 🔹 `sorted`
31. Відсортувати числа за зростанням.
32. Відсортувати числа за спаданням.
33. Відсортувати рядки за алфавітом.
34. Відсортувати рядки за довжиною.
35. Відсортувати список людей за віком.
36. Відсортувати список людей за іменем.
37. Відсортувати числа так, щоб парні йшли першими.
38. Відсортувати рядки так, щоб паліндроми були першими.
39. Відсортувати дати від нових до старих.
40. Відсортувати студентів за середнім балом.

## 🔹 `distinct`
41. Прибрати дублікати чисел.
42. Прибрати дублікати рядків.
43. Прибрати дублікати імен у списку людей.
44. Прибрати дублікати чисел і відсортувати результат.
45. Прибрати дублікати рядків у верхньому регістрі.

## 🔹 `peek`
46. Вивести в консоль усі елементи списку перед їх перетворенням.
47. Вивести в консоль елементи після фільтрації, але перед `map`.
48. Вивести кожного користувача, який проходить фільтр по віку.
49. Вивести довжину кожного слова перед перетворенням.
50. Додати лог `"Обробляю: <елемент>"` під час обробки.

## 🔹 `takeWhile` (Java 9+)
51. Взяти числа, поки вони менші за 100.
52. Взяти рядки, поки їх довжина менша за 5.
53. Взяти користувачів, поки їх вік < 18.
54. Взяти числа, поки вони парні.
55. Взяти рядки, поки вони починаються на `"A"`.

## 🔹 `dropWhile` (Java 9+)
56. Пропустити числа, поки вони менші за 10.
57. Пропустити рядки, поки їх довжина < 4.
58. Пропустити користувачів, поки їх вік < 18.
59. Пропустити числа, поки вони парні.
60. Пропустити рядки, поки вони починаються на `"B"`.
