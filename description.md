# Java Hille Summer 2025

This repository collects coursework, lecture materials, and practice projects for the Java Hille Summer 2025 program. It includes:

- Classroom exercises stored under the `cw/` and `tasks/` directories.
- Lecture examples and reference solutions in the `lec/` and `tz_example/` folders.
- Maven-based sample applications located in `mvnProjects/`.
- Supplemental projects such as the `BlackJack` game implementation.

Use this repository to follow along with the curriculum, review examples, and experiment with Java concepts introduced during the course.
